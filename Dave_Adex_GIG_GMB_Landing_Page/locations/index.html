How to use a geographic page

Landmark first. Brief second. Service route third.

Use the page to describe the actual area, then follow the internal link to the service page that fits the work.

01

Name the real area

Give the venue, street, neighbourhood or landmark that helps the team understand the project context.

02

Describe the work

State the people, media, event or local-growth task rather than repeating the location keyword.

03

Confirm the handoff

Agree on timing, access, approvals, remote coordination and what the client is actually buying.

Need a different area?

Send the actual location and brief. New geographic pages should follow verified rank-map opportunities and real customer areas.
