# Geographic Relevance Implementation — Dave Adex GIG & GMB Agency

## What was built

- Location hub: `locations/index.html`
- 6 geographic service-area pages
- Homepage Areas Served preview with editorial links to every location page
- Areas Served links added to the navigation and footer across the site
- Each geographic page links to relevant Core service pages and supporting guides
- Each geographic page contains a visible external geographic reference and a Google Maps area link
- Sitemap expanded with 7 location URLs

## Geographic pilot set

### Ibadan

- University of Ibadan / Oduduwa Road / Ibadan North
- Bodija
- Mokola

### Lagos

- Ikeja
- Yaba
- Surulere

These are real geographic anchors selected from mapped or official local references. No new office, rating, review, partner, storefront or GBP listing is claimed.

## Content approach

Each page uses a service + landmark/area + city target in the title and H1, then explains what changes in the brief for that area: venue access, call time, equipment handoff, customer-facing address, service area, usage, approval or remote coordination. The pages do not repeat the area name as filler.

Lagos pages explicitly state that Lagos work is remote or coordinated at an agreed project venue and does not imply a Lagos branch. The approved GBP identity remains:

`University of Ibadan, Oduduwa Road, Ibadan North, Ibadan, Oyo State, 200005, Nigeria`

## What cannot be completed from the workspace

- No rank-map CSV or position data was supplied, so these are pilot geographic pages rather than pages claimed to target positions 4–6.
- No verified local search-volume or demographic dataset was supplied.
- Inbound geographic backlinks, local sponsorships and rank-map movement require a production domain and off-site activity.
- The sitemap still uses relative paths because no production domain was supplied.
